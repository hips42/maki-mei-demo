現在のGit管理ファイルから利用者の個人名・学校名・学校のURLを除去し、汎用のプレイヤー1/2へ変更。英語7問に含まれた人名も置換した。全324問のID・正答・種別・学期と、人物名以外の問題文を維持。出版社の出典・学期分類根拠は保持する。

公開するゲームの実行ファイルはindex.html、extra_questions.js、curriculum_questions.js、assets/nekoda-nekoo.png。GitHub Pagesのブランチ配信では他の追跡ファイルも取得可能なため、README・docs・問題監査JSON・テスト・package情報も点検・匿名化した。GitHub側のPages設定は変更していない。

旧ブラウザ記録を消さないため、既存ストレージキーと旧プレイヤー識別子だけはUnicode表記の互換情報として残す。これは暗号化や秘匿化ではなく、旧形式の読み書きに必要な公開互換コード。画面・問題には旧名称を表示しない。既存レコードの名前変更・削除・再初期化をしない。

既存Git履歴・既存GitHubリポジトリ名・URL・remoteは変更しない。過去コミットには以前の情報が残る。完全な履歴除去やリポジトリ改名には別の明示的な作業が必要。未追跡のローカルREADME.txtは触れずコミットに含めない。

今回はローカルコミットまで。push・デプロイ・GitHubリポジトリ作成なし。公開中サイトはこの作業では更新されない。
