# 実ブラウザ確認（2026-10-18）

Chrome 155.0.8059.80をPlaywrightで実行。専用の一時ブラウザコンテキストと127.0.0.1の一時配信先を使用した。普段のChromeプロファイル、公開サイト、既存学習記録は使用・削除していない。履歴保持の検証にはテスト専用の過去履歴を投入した。

- おためしのoptionがdisabled、1・2・3学期が選択可能。
- 3学期×5科目（漢字混合・読み・書き取り・英単語／語形・英熟語／表現）の全15組み合わせで10問完走。学期・科目・問題IDの重複なしを確認。
- 読み・書き取り・混合・表現は全問不正解でも10問完走し0点。単語は正誤交互で50点。手書きは実マウスで線を描き、正解表示後に自己採点ボタンを操作。
- 10問終了まで保存されず、結果画面で保存される。再挑戦で学習記録・本日の回数を表示。過去履歴と別プレイヤーの記録が保持され、リロード後も保存内容が一致。
- 学期を切り替えた3回の完走後に開始不可。別プレイヤーは開始でき、100点でその日の達成表示になる。
- 幅320・375・390pxとデスクトップ1280pxで横方向のはみ出しなし。320pxでは全15組み合わせの問題画面・結果画面・記録画面も寸法検査。スタート・書き取り・英語問題・結果の画像を目視確認し、文字・ボタンの欠けなし。縦方向は通常のスクロールで閲覧可能。
- JavaScript実行エラー、必要リソースの取得失敗なし。

結果：`npm.cmd test` 15件成功、`npm.cmd run test:browser` 3件成功（15組み合わせの出題を含む）。実ブラウザで新たな不具合は見つからず、アプリ本体の追加修正は行っていない。

再実行には `npm ci` とインストール済みChromeが必要。テストコードは `tests/browser.test.cjs`。一時コンテキストは終了時に閉じ、スクリーンショットだけ `test-results/` に残す。GitHubへのpushは行っていない。
