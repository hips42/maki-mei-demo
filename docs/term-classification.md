# 2026年度・中1 学期別出題の調査と実装

調査日：2026-10-18。対象は一般向け、中学1年、英語 NEW CROWN English Series 1（三省堂）、国語1（光村図書出版）。2026年度に使う令和7年度版の出版社資料を参照した。

## 根拠と確認できた範囲

2. [三省堂・令和7年度版各種資料](https://tb.sanseido-publ.co.jp/07ncpr/) → [1年 指導・学習内容一覧 PDF](https://tb.sanseido-publ.co.jp/07ncpr/images/top/07nc_1_curric.pdf)：2ページの月別計画。p.1が4〜7月、p.2が9〜3月。文法事項と配当月を確認した。
3. [三省堂・単元別指導・評価計画 PDF](https://tb.sanseido-publ.co.jp/07ncpr/images/top/07nc_hyoka_2501.pdf)：1年はPDF pp.2〜17。文法の単元目標を補助確認した。
4. [光村図書・年間指導計画・評価計画資料](https://www.mitsumura-tosho.co.jp/kyokasho/c-kokugo/keikaku) → [1年 年間指導計画例 PDF](https://www.mitsumura-tosho.co.jp/download_file/view/28dc859f-f9cf-4e41-8421-6e372f8be976/609)：28ページの月別計画。単元名、学習事項、配当月を確認した。
5. [光村図書・1年教材別資料](https://www.mitsumura-tosho.co.jp/kyokasho/c-kokugo/material1nen)：現行版の単元名・配列を補助確認。作品本文や練習問題は転用していない。

したがって、本アプリの学期は**出版社の月別計画を4〜7月＝1学期、9〜12月＝2学期、1〜3月＝3学期と対応させた参考区分**である。学校がこの進度を採用しているとは主張しない。画面に「出版社の年間指導計画を参考（学校の実際の進度は未確認）」と表示する。

## 学期と単元の対応

英語の主要Lessonは、1学期がLesson 1〜4、2学期がLesson 5〜7、3学期がLesson 8〜9。1学期は現在形・can・疑問詞、2学期は三単現・現在進行形・一般動詞過去形、3学期はbe動詞過去形・過去進行形・未来表現を練習する。指定語形も扱うため「英単語・語形」「英熟語・表現」と表示する。表現問題は2語の空欄補充で、使用語や語数を指定する。

国語の配列では、おおむね1学期が「学びをひらく」「新しい視点で」「言葉に立ち止まる」、2学期が「心の動き」「筋道を立てて」「いにしえの心にふれる」「価値を見いだす」、3学期が「自分を見つめる」。今回は既存の漢字練習の形式を維持し、以下の学習事項で使う用語を読み・書き取りの対象とした。

- 1学期：5月の音声の仕組み、6月の情報整理・比較分類・説明、6月の表現技法。根拠は国語計画PDF pp.3、6〜8。
- 2学期：10月の聞き取りと記録、意見と根拠、引用と出典を伴う報告。根拠は同PDF pp.14、16〜17。
- 3学期：1月の単語の分類、2月の随筆・描写。根拠は同PDF pp.25〜26。

これは**学習用語の漢字を練習する補充問題**であり、各教材の新出漢字・新出音訓を網羅した問題集ではない。また、文学作品の内容理解や英語の全学習事項を網羅するものでもない。

## 既存220問の分類結果

全問題の問題文、正答、ID、科目を保持した。単元の見出しや学習事項に出題語そのものが明示される国語16問のみ、出版社計画への対応として分類した。

- 1学期：比較、情報、説明、表現。それぞれ読み・書き取りの計8問。
- 2学期：意見、結果、関係、記録。それぞれ読み・書き取りの計8問。

残る204問は、今回読めた資料から出題語・表現と月別単元の明確な対応を確認できず、`term: "trial"` のまま出題対象外。一般的な単語、既習語、題材に関係しそうな語という理由では分類していない。新出語一覧を全件取得して照合したという意味ではなく、未確認のものを保留した結果である。

16問は `source_status: "plan_vocabulary"` とし、**`verified: false` を維持**した。確認したのは「出版社の計画に学習用語として明示されること」であり、「教科書の掲載語一覧との照合済み」や「学校の実施学期確認済み」ではない。

## 追加問題と現在の出題数

不足分として独自に104問（読み22、書き取り22、英単語・語形30、英熟語・表現30）を作成。既存問題と同じ語・科目・学期の追加は避けた。国語の用例と設問、英語の空欄補充は独自作成し、教材の登場人物や本文・問題集の文章を使用していない。

各学期とも読み10問、書き取り10問、英単語・語形10問、英熟語・表現10問。漢字混合は各20問。全体は既存220問＋追加104問＝324問、出題可能なのは120問、保留は204問。

追加問題は `source_status: "plan_original"`、`verified: false`。`school_year: 2026`、`grade: 1`、`alignment_basis: "publisher_plan"`、単元ID、根拠URLとPDF内の位置を持つ。すべて `school_pacing_verified: false`。出題処理は学期・年度・学年・科目・単元台帳・根拠情報の対応を検査し、`verified: true` だけでは採用しない。

[全問の分類結果と根拠](classification-results.json)に324問をID単位で記録した。`origin: "legacy"` が既存220問、`origin: "original_2026"` が追加104問。各行の `classification_status`、`classification_reason`、`alignment_unit`、`source_url`、`source_locator` で分類理由を追跡できる。単元台帳は同JSONの `units` にある。

## 実装・再確認

`curriculum_questions.js` は既存220問の読み込み後に分類メタデータを適用し、不足問題を追加する。元データの問題文・正答は変更しない。HTMLからは `extra_questions.js` の次に読み込む。データファイルが読み込めない場合は未分類問題へフォールバックせず、開始を無効にする。

おためし選択不可、localStorageキーと既存保存形式、プレイヤー別記録、1日3回、100点で当日達成、不正解でも10問完走してから結果保存する流れを維持した。途中の正誤フィードバックと点数表示も既存どおり。結果ボタンの連打による重複保存を防止する。CSSと画像は変更していない。

検証：`node --test tests/quiz.test.cjs`。DOM代替環境で実コードを実行し、既存220問保持、全15組み合わせの学期・科目分離と10問完走・50点採点、4科目全問不正解、既存履歴保持、100点達成、3回完走後の開始禁止、プレイヤー別制限、結果の二重保存防止、根拠や年度が不整合なデータの除外を確認する。続いてChromeで描画・手書きポインター操作を含む実ブラウザテストも実施済み。詳細は [実ブラウザ確認](browser-verification.md)。

`node scripts/audit-questions.cjs --write` でこのディレクトリの分類JSONとルートの `question-audit.json` を再生成できる。引数なしは標準出力への読み取り専用調査。GitHubへのpush、LIFF化、成績同期、公開環境の分離は行っていない。
